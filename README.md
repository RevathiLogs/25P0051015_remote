### Markdown Syntax

For inline code formatting we use backticks. 

For eg., \`print("Hello World)\`
here we have used the escape character \ to show the syntax. On applying it we get the output as `print("Hello World")` .

Markdown allows you to apply:
1. Bold
2. Italic
3. Inline code formatting

There is also syntax to include:
- Hyperlink
- Image


| Expected Result | Syntax |
| --- | ---|
| "Science" in bold | \*\*Science\*\*|
|"Math" in italic  | \*Math\* |
